Como funciona

O fluxo completo

PR aberto → CI automático
Typecheck · Lint · Testes · Build · Audit · SonarCloud · Validação de permissão
Merge em develop → Deploy automático
Build Docker → push Artifact Registry → deploy Cloud Run (develop)
GitHub Release → Deploy automático em staging
Build Docker → push AR com tag da versão → deploy Cloud Run (staging)
Senior promove para produção (manual)
Copia imagem de staging → produção. Sem rebuild. Canary opcional: 10% → 50% → 100%
Problema em produção → Rollback imediato
1 clique. Volta para qualquer revisão anterior. Zero downtime.
Segurança e controle

Proteção em cada camada

🔐

Sem chaves no GitHub

Workload Identity Federation — o GCP valida a identidade pelo contexto do workflow. Nenhuma credencial armazenada.

🔒

Secrets nunca saem do GCP

Auth0, banco de dados, API keys — tudo no GCP Secret Manager. O Cloud Run os lê diretamente na inicialização.

🎯

Deploy controlado

Produção só pelo time seniors. Branch protection exige CI verde e aprovação antes de qualquer merge.

🧹

Limpeza automática

Artifact Registry limpo toda semana — imagens antigas deletadas automaticamente. Sem custo acumulando.

2

Configurar GitHub

./setup-github.sh --owner bankme-tech --repo meu-repo

3
